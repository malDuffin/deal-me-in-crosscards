# Deal Me In — CrossCards

An 11×11 crossword of poker. Fixed cards stay put; gold seats mark where your hand belongs. Rows and columns score as poker hands.

## Play

- **How to play / Training / Puzzles** — original tables
- **Endless tables** — continuous AI-generated puzzles (Easy → Expert)
- **Free play** — twelve cards, chase the high score

Tap a card then a seat, or drag. Ace-high tray. Three card faces in Settings (large rank is the default), plus colorblind colors, music, and mute.

## Stack

TanStack Start, React 19, Tailwind v4, GSAP, Zustand, xAI for endless tables.

```bash
npm install
npm run dev
```

Runs at `http://localhost:8080`.

```bash
npm run build
npm run preview
```
